# ChromSeek Checkpoints

Before running the corresponding tasks in this repository, please visit the project
[GitHub Releases page](https://github.com/zzzlnb/chromSeek/releases) and download the
required model weight files (`.pth`), then place them in this directory.

Common checkpoint files include:

- `best_model_448k_200bp.pth`
- `chromSeek_hic_enhancement.pth`
- `chromSeek_tad_prediction.pth`
- `chromSeek_loop_prediction.pth`
- `chromSeek_chiapet_prediction.pth`
- `transfer_multiomics_best.pth`

Different tasks use different checkpoints. Please choose the file required by the
relevant script or tutorial.
